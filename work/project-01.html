The Challenge

The client came to us with a Figma design for a premium e-commerce store but an outdated WordPress site that was slow, inaccessible, and haemorrhaging sales from a poor checkout experience. They needed a ground-up rebuild delivered in under 6 weeks.

Key pain points included:

  • No mobile optimisation — 70% of traffic was mobile
  • Page load times of 6+ seconds on mobile
  • Cart abandonment at 75% due to a clunky checkout
  • Zero accessibility compliance (failed WCAG AA checks)
  • No email marketing integration

My Approach

I performed a pixel-perfect conversion of the Figma designs into a custom WordPress theme built from scratch using semantic HTML5, SCSS, and vanilla JavaScript. WooCommerce was configured with a streamlined, 2-step checkout.

Performance was central: every image was compressed with WebP conversion, critical CSS was inlined, fonts were loaded with font-display: swap, and a full Core Web Vitals audit was completed before handover.

  • Built a custom WordPress child theme — zero page-builder overhead
  • Integrated Brevo (Sendinblue) via REST API for email automation
  • Implemented Google Analytics 4 with enhanced eCommerce tracking
  • Configured Google Maps for store locator functionality
  • Applied WCAG 2.1 AA across all pages — keyboard nav, ARIA, contrast ratios
  • Set up XML sitemap, meta tags, and schema markup for SEO

Results

Within 60 days of launch, the client recorded measurable improvements across every KPI they had identified:

+40% Conversion Rate
98 Lighthouse Score
-65% Page Load Time

Key Learnings

This project reinforced the business value of performance-first development and accessibility as a feature, not an afterthought. The Brevo API integration also deepened my expertise in transactional email flows triggered from WooCommerce order hooks.
